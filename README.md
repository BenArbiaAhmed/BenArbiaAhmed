## Featured projects

### 🧠 StudyAgent — Multi-agent AI Study Assistant
> LangGraph · Chroma · Gemini · Streamlit

Supervisor-driven multi-agent system that routes user intents to specialized analyzer, RAG QA, and flashcard-generation agents. Features PDF-to-Markdown extraction, semantic indexing, Brave search + Firecrawl fallback, and a critic-refiner loop for output quality.

### 🏋️ FormTrack — AI Sports Coaching with Computer Vision
> FastAPI · MediaPipe · OpenCV · React

Real-time pose estimation platform that detects form phases, counts reps, and delivers instant corrective audio feedback for push-ups, squats, and tricep dips. Full-stack product with JWT auth, workout analytics, and live SSE video streaming.

### 🔊 EchoQuest — Audio Semantic Search Engine
> FastAPI · Whisper · BGE Embeddings · Supabase · React + TypeScript

End-to-end audio retrieval pipeline: upload → FFmpeg preprocessing → Whisper transcription → overlapping chunking → vector search with cross-encoder reranking. Timestamp-aware playback with jump-to-segment controls.
